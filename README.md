### Projet : Prédiction du prix des logements avec Machine Learning

### Introduction
Le marché immobilier repose sur l'estimation de la valeur des biens afin de faciliter les décisions d'achat, de vente et d'investissement. Cependant, déterminer le prix approprié d'une maison peut être complexe, car sa valeur dépend de plusieurs caractéristiques telles que sa superficie, son emplacement, le nombre de chambres, le nombre de salles de bain et d'autres facteurs.
Dans ce contexte, ce projet consiste à exploiter des techniques de Machine Learning afin de développer un modèle capable d'estimer le prix d'une maison à partir de ses caractéristiques.

### Problème métier
Les acteurs du marché immobilier peuvent rencontrer des difficultés à déterminer rapidement et précisément le prix approprié d'un bien immobilier.
Une mauvaise estimation peut entraîner :

•	une vente trop lente lorsque le prix est surévalué 

•	une perte financière lorsque le bien est sous-évalué 

•	une prise de décision moins efficace lors des transactions immobilières

L'utilisation d'un modèle prédictif peut donc contribuer à fournir une estimation plus objective et cohérente du prix des logements.

### Objectif du projet
L'objectif principal est de développer un modèle de Machine Learning capable de prédire le prix d'une maison à partir de ses caractéristiques.
Le modèle devra fournir une estimation suffisamment fiable pour contribuer à la prise de décision dans le contexte immobilier.

### Problématique Data Science
Peut-on prédire avec suffisamment de précision le prix d'une maison à partir de ses caractéristiques disponibles dans les données ?

### Dictionnaire des données
Les principales variables du dataset sont les suivantes :
Variable	Description

**price**	    : Prix de la maison

**area**	    : Superficie de la maison

**bedrooms**	: Nombre de chambres

**bathrooms** :	Nombre de salles de bain

**stories** 	: Nombre d'étages

**mainroad**	: Accès à la route principale

**guestroom**	: Présence d'une chambre d'amis

**basement**	: Présence d'un sous-sol

**hotwaterheating**	: Présence d'un système de chauffage d'eau

**airconditioning**	: Présence de la climatisation

**parking**	        : Nombre de places de parking

**furnishingstatus**	: État d'ameublement

### Feuille de route du projet
Le projet suit les principales étapes d'une démarche de Data Science :

**Phase 1** : Compréhension du problème métier
Définition du contexte immobilier, du problème métier et des objectifs du projet.

**Phase 2** : Compréhension des données
Exploration du dataset, identification des variables et analyse de leur structure.

**Phase 3** : Nettoyage des données
Traitement des valeurs manquantes, vérification des doublons, détection des éventuelles anomalies et préparation des données.

**Phase 4** : Analyse exploratoire des données (EDA)
Analyse statistique et graphique des variables afin d'identifier les principales tendances, distributions, relations et corrélations.

**Phase 5** : Apprentissage des modèles
Préparation des données pour le Machine Learning, entraînement de plusieurs modèles de régression et comparaison de leurs performances.

**Phase 6** : Évaluation des modèles
Évaluation des modèles à l'aide de métriques adaptées à un problème de régression et sélection du modèle le plus performant.
